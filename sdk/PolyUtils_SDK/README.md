# PolyUtils: контракт бібліотеки, версія API 1.0

## 1. Загальна інформація

**Назва:** PolyUtils  
**Версія API:** 1.0  
**Платформа:** Windows x64, MSVC, C++20, конфігурація Release.

Бібліотека призначена для виконання основних операцій із поліномами: додавання, множення, обчислення значення, знаходження похідної та первісної.

Файли SDK:

- `include/PolyUtils.h` — заголовочний файл;
- `lib/PolyUtils.lib` — імпортна бібліотека для неявного зв’язування з DLL;
- `bin/PolyUtils.dll` — динамічна бібліотека.

Бібліотеку зібрано з параметром `/MD` у конфігурації Release та `/MDd` у конфігурації Debug. Для запуску DLL на іншому комп’ютері може знадобитися встановлення відповідного Microsoft Visual C++ Redistributable.

## 2. Угода про зв’язування

Усі функції оголошені з `extern "C"`, що забезпечує C-сумісне іменування та запобігає декоруванню імен за правилами C++.

Для експорту функцій DLL використовується `__declspec(dllexport)`, а для імпорту в клієнтській програмі — `__declspec(dllimport)`.

У заголовку `PolyUtils.h` передбачені такі макроси:

- `POLYUTILS_EXPORTS` — визначається під час збирання DLL;
- `POLYUTILS_STATIC` — визначається для статичної версії бібліотеки;
- якщо жоден із цих макросів не визначений, використовується `__declspec(dllimport)`.

У кореневому `CMakeLists.txt` макрос `POLYUTILS_EXPORTS` задається для динамічної бібліотеки, а `POLYUTILS_STATIC` — для статичної.

**Неявне зв’язування (Implicit Linking):** використовуються заголовок `PolyUtils.h`, імпортна бібліотека `PolyUtils.lib` і DLL, доступна під час запуску. У клієнтській програмі макроси `POLYUTILS_EXPORTS` та `POLYUTILS_STATIC` визначати не потрібно.

**Явне зв’язування (Explicit Linking):** DLL завантажується через `LoadLibrary`, а адреси функцій отримуються за допомогою `GetProcAddress`. Після завершення роботи бібліотека вивантажується через `FreeLibrary`.

## 3. Формат даних і загальні правила

Поліном подається масивом коефіцієнтів типу `double`.

Елемент `coeffs[i]` є коефіцієнтом при \(x^i\). Наприклад, масив `{1, 2, 3}` відповідає поліному \(1 + 2x + 3x^2\).

Параметр `n` означає кількість коефіцієнтів, а не степінь полінома. Степінь дорівнює `n - 1`, якщо старший коефіцієнт ненульовий.

Загальні правила:

- допустима кількість коефіцієнтів кожного вхідного полінома — від 1 до 10000 включно;
- бібліотека не виділяє та не звільняє пам’ять для вихідного масиву;
- пам’ять для результату виділяє викликач;
- вхідні масиви не змінюються;
- вихідний буфер не повинен перекриватися з вхідними масивами;
- результат не нормалізується: старші нульові коефіцієнти не відкидаються, а кількість елементів визначається формулою відповідної функції;
- максимальна кількість коефіцієнтів результату множення становить 19999, оскільки вона дорівнює `na + nb - 1`;
- функції не кидають винятків навмисно; для некоректних параметрів, які перевіряються реалізацією, повертаються коди помилок;
- викликач відповідає за те, щоб вхідні масиви містили щонайменше кількість елементів, зазначену в параметрах `n`, `na` або `nb`, а вихідний масив містив щонайменше `outCapacity` елементів. Бібліотека не може перевірити фактичний розмір виділеної пам’яті. Порушення цієї вимоги може призвести до невизначеної поведінки, зокрема аварійного завершення програми;
- бібліотека не перевіряє окремо скінченність числових аргументів. Значення `NaN` та нескінченності можуть впливати на результат обчислень, але не мають окремого коду помилки.

## 4. Коди повернення

Для функцій, які формують масив результату:

- `>= 0` — успішне виконання; повертається кількість елементів результату;
- `-1` (`POLY_ERR_NULL`) — обов’язковий вказівник дорівнює `nullptr`;
- `-2` (`POLY_ERR_SIZE`) — некоректний розмір вхідних даних;
- `-3` (`POLY_ERR_BUFFER`) — недостатня ємність вихідного буфера.

Перевірки виконуються в такому порядку: спочатку вказівники, потім розміри, після цього ємність вихідного буфера.

У разі повернення коду помилки через некоректні параметри вихідний буфер не змінюється, оскільки перевірки вказівників, розмірів і ємності буфера виконуються до запису результату.

Функція `PolyEvaluate` повертає `0` у разі успіху або відповідний від’ємний код помилки.

## 5. Опис функцій API

### 5.1. PolyAdd — додавання поліномів

```cpp
int PolyAdd(
    const double* a, int na,
    const double* b, int nb,
    double* out, int outCapacity
);
```

Додає два поліноми `a` та `b`.

- `a`, `b` — масиви коефіцієнтів;
- `na`, `nb` — кількість коефіцієнтів;
- `out` — масив для результату;
- `outCapacity` — ємність вихідного масиву.

Необхідна ємність: `max(na, nb)` елементів.

Повертає `max(na, nb)` у разі успіху або код помилки.

### 5.2. PolyMultiply — множення поліномів

```cpp
int PolyMultiply(
    const double* a, int na,
    const double* b, int nb,
    double* out, int outCapacity
);
```

Множить два поліноми.

Необхідна ємність: `na + nb - 1` елементів.

Повертає `na + nb - 1` у разі успіху або код помилки.

За максимально допустимих розмірів вхідних масивів результат може містити до 19999 коефіцієнтів.

### 5.3. PolyEvaluate — обчислення значення полінома

```cpp
int PolyEvaluate(
    const double* coeffs, int n,
    double x, double* result
);
```

Обчислює значення полінома в точці `x` за схемою Горнера.

- `coeffs` — масив коефіцієнтів;
- `n` — кількість коефіцієнтів;
- `x` — точка обчислення;
- `result` — вказівник на змінну, у яку записується результат.

Повертає `0` у разі успіху або код помилки.

### 5.4. PolyDerivative — похідна полінома

```cpp
int PolyDerivative(
    const double* coeffs, int n,
    double* out, int outCapacity
);
```

Обчислює коефіцієнти похідної полінома.

Необхідна ємність: `max(n - 1, 1)` елементів.

- Якщо `n >= 2`, повертає `n - 1`.
- Якщо `n == 1`, повертає `1` і записує `out[0] = 0`, оскільки похідна від константи дорівнює нулю.

У разі некоректних параметрів повертає код помилки.

### 5.5. PolyIntegral — первісна полінома

```cpp
int PolyIntegral(
    const double* coeffs, int n,
    double constant,
    double* out, int outCapacity
);
```

Обчислює коефіцієнти первісної полінома із заданою сталою інтегрування.

Необхідна ємність: `n + 1` елементів.

Результат формується за правилами:

- `out[0] = constant`;
- `out[i + 1] = coeffs[i] / (i + 1)` для `i` від `0` до `n - 1`.

Повертає `n + 1` у разі успіху або код помилки.

## 6. Приклади використання

### 6.1. Неявне зв’язування (Implicit Linking)

```cpp
#include "PolyUtils.h"

double p[] = {1, 2, 3};
double r[8];

int n = PolyDerivative(p, 3, r, 8);
// n = 2, r = {2, 6}
```

Для цього способу потрібні заголовок `PolyUtils.h`, імпортна бібліотека `PolyUtils.lib` і DLL, доступна під час запуску.

### 6.2. Явне зв’язування (Explicit Linking)

```cpp
#include <windows.h>

typedef int (*PolyEvaluateFn)(
    const double*, int, double, double*
);

HMODULE h = LoadLibraryA("PolyUtils.dll");

if (h != nullptr) {
    auto ev = reinterpret_cast<PolyEvaluateFn>(
        GetProcAddress(h, "PolyEvaluate")
    );

    if (ev != nullptr) {
        double p[] = {1, 2, 3};
        double v = 0;

        int status = ev(p, 3, 2.0, &v);
        // status = 0, v = 17
    }

    FreeLibrary(h);
}
```

Перед викликом функції необхідно перевірити успішність `LoadLibraryA` та `GetProcAddress`.

## 7. Перевірка граничних випадків

| Випадок | Очікуваний результат |
|---|---|
| Обов’язковий вказівник дорівнює `nullptr` | `-1` |
| Розмір вхідного масиву менше 1 або більше 10000 | `-2` |
| Недостатній вихідний буфер | `-3` |
| Похідна від константи | `1`, результат `{0}` |
| Обчислення `{1, 2, 3}` у точці `x = 2` | `0`, значення `17` |
| Старший коефіцієнт дорівнює нулю | Нульовий коефіцієнт зберігається в результаті |
| Числові аргументи містять `NaN` або нескінченність | Окремий код помилки не повертається |
